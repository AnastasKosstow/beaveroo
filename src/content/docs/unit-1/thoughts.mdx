:::tip
В тази секция се потапяме във вътрешната работа на AI agent — способността му да разсъждава (reason) и да планира. Ще разгледаме как agent-ът използва вътрешния си диалог, за да анализира информация, да разбива сложни проблеми на управляеми стъпки и да решава какъв action да предприеме след това.

Освен това ще представим подхода ReAct — техника за prompting, която насърчава модела да мисли „стъпка по стъпка“, преди да действа.
:::

Thoughts представляват **вътрешните процеси на reasoning и planning на Agent-а** за решаване на задачата.

Това използва капацитета на Large Language Model (LLM) на agent-а **да анализира информация, когато тя му е представена в prompt-а** — по същество неговият вътрешен монолог, докато работи по даден проблем.

Thoughts на Agent-а му помагат да оцени текущите observations и да реши какъв(и) да бъде(ат) следващият(ите) action(s). Чрез този процес agent-ът може да **разбива сложни проблеми на по-малки, по-управляеми стъпки**, да осмисля минал опит и непрекъснато да коригира плановете си въз основа на нова информация.

## 🧠 Примери за често срещани типове Thought

| Тип Thought | Пример |
|-------------|--------|
| Planning | „Трябва да разбия тази задача на три стъпки: 1) събиране на данни, 2) анализ на тенденциите, 3) генериране на отчет“ |
| Analysis | „Съдейки по съобщението за грешка, проблемът изглежда е в параметрите за връзка с базата данни“ |
| Decision Making | „Предвид бюджетните ограничения на потребителя, трябва да препоръчам средния вариант“ |
| Problem Solving | „За да оптимизирам този код, първо трябва да го профилирам, за да открия тесните места“ |
| Memory Integration | „Потребителят по-рано спомена, че предпочита C#, така че ще дам примерите на C#“ |
| Self-Reflection | „Последният ми подход не проработи добре, трябва да опитам различна стратегия“ |
| Goal Setting | „За да завърша тази задача, първо трябва да установя критериите за приемане“ |
| Prioritization | „Уязвимостта в сигурността трябва да бъде отстранена, преди да се добавят нови функции“ |

> **Бележка:** При LLMs, fine-tuned за function-calling, мисловният процес е по избор. Повече подробности ще бъдат разгледани в секцията за Actions.

## 🔗 Chain-of-Thought (CoT)

**Chain-of-Thought (CoT)** е техника за prompting, която насочва модела **да обмисли проблема стъпка по стъпка, преди да даде финален отговор.**

Обикновено започва с:
> *„Let's think step by step.“*

Този подход помага на модела **да разсъждава вътрешно**, особено при логически или математически задачи, **без да взаимодейства с външни tools**.

### ✅ Пример (CoT)

```text
Question: What is 15% of 200?
Thought: Let's think step by step. 10% of 200 is 20, and 5% of 200 is 10, so 15% is 30.
Answer: 30
```

## ⚙️ ReAct: Reasoning + Acting

Ключов метод е **подходът ReAct**, който комбинира „Reasoning“ (Think) с „Acting“ (Act).

ReAct е техника за prompting, която насърчава модела да мисли стъпка по стъпка и да редува actions (като използване на tools) между стъпките на reasoning.

Това позволява на agent-а да решава сложни многостъпкови задачи, като редува:
- Thought: вътрешно reasoning
- Action: използване на tool
- Observation: получаване на изхода от tool-а

### 🔄 Пример (ReAct)

```text
Thought: I need to find the latest weather in Paris.
Action: Search["weather in Paris"]
Observation: It's 18°C and cloudy.
Thought: Now that I know the weather...
Action: Finish["It's 18°C and cloudy in Paris."]
```

## 🔁 Сравнение: ReAct срещу CoT

| Характеристика | Chain-of-Thought (CoT) | ReAct |
|----------------|------------------------|-------|
| Логика стъпка по стъпка | ✅ Да | ✅ Да |
| Външни tools | ❌ Не | ✅ Да (Actions + Observations) |
| Най-подходящ за | Логика, математика, вътрешни задачи | Търсене на информация, динамични многостъпкови задачи |

:::tip
Скорошни модели като **Deepseek R1** или **o1 на OpenAI** са fine-tuned да *мислят, преди да отговорят*. Те използват структурирани tokens като `<think>` и `</think>`, за да отделят изрично фазата на reasoning от финалния отговор.

За разлика от ReAct или CoT — които са стратегии за prompting — това е **техника на ниво обучение**, при която моделът се научава да мисли чрез примери.
:::
