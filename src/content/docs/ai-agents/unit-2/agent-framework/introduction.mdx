Добре дошъл в този модул, в който ще се научиш да изграждаш Agents с **Microsoft Agent Framework**: framework-а с отворен код на Microsoft за Agents и multi-agent системи.

В Unit 1 мина по дългия път. Първо написа Agent на ръка в [Dummy Agent Library](/ai-agents/unit-1/dummy-agent-library/), а после го изгради с [`Microsoft.Extensions.AI`](/ai-agents/unit-1/tutorial/). Библиотеката пое цикъла Thought → Action → Observation, но две неща останаха за теб: сам пазеше разговора в списъка `history` и сам се грижеше за грешките. За един въпрос и един tool това е достатъчно. Когато Agent-ът трябва да помни, да иска разрешение преди важно действие или да работи в екип с други Agents, ти трябва нещо повече.

Това добавя Microsoft Agent Framework. Той стъпва върху `Microsoft.Extensions.AI`, така че наученото дотук остава в сила.

## Преглед на модула

Модулът минава през основните концепции на framework-а и ги показва с код, който изпълняваш на своя компютър. Двете му големи теми са:

- **Agents**: един Agent, който мисли с LLM, използва tools, помни разговора и може да бъде наблюдаван и контролиран.
- **Workflows**: няколко стъпки, функции или Agents, свързани в граф, в който ти определяш реда на изпълнение.

В този Unit Alfred от Unit 1 се връща. Този път отвътре го задвижва Microsoft Agent Framework. Семейство Wayne 🦇 отсъства, а той трябва да организира парти в Wayne Manor: тема, меню, кетъринг, музика, покани и списък с гости. Ще го следим урок по урок.

## Съдържание

### 1️⃣ Защо Microsoft Agent Framework

Има различни frameworks за създаване на AI агенти. За Python например можеш да използваш smolagents, LlamaIndex или LangGraph. В този курс ще работим с Microsoft Agent Framework, защото фокусът ни е върху разработката на агенти с .NET.

### 2️⃣ Първият ти Agent

Ще създадеш проекта, с който ще работим през целия модул, и ще превърнеш локалния модел в Agent с един ред: `AsAIAgent`. Ще сравним кода с този от Unit 1, за да видиш какво точно поема framework-ът.

### 3️⃣ Tools

Както видя в Unit 1, tools са функциите, чрез които един Agent действа. Ще дадем на Alfred tools за менюто и кетъринга, ще видим как избира между тях и какво се случва, когато един tool се провали.

### 4️⃣ Sessions

Моделът не помни нищо между заявките. `AgentSession` пази разговора вместо теб. Ще превърнем Alfred в чат, а после ще запишем разговора във файл, за да продължи и след рестарт на програмата.

### 5️⃣ Middleware

Middleware е код, който се изпълнява около всяка стъпка на Agent-а. С него ще измерим колко време и tokens отнема един отговор и ще накараме Alfred да иска разрешение, преди да похарчи пари.

### 6️⃣ Multi-Agent Systems

Един Agent с много задачи лесно се обърква. Ще разделим работата между специалисти: готвач и DJ, които Alfred управлява като свои tools.

### 7️⃣ Workflows

Понякога не искаш Agent-ът да решава какво следва. С Workflows ти задаваш стъпките и връзките между тях. Ще изградим workflow, който сортира отговорите на поканите, и екип от двама Agents, които пишат покана един след друг.

Между уроците има два кратки quiz-а, а накрая те очаква финален quiz за целия модул.
