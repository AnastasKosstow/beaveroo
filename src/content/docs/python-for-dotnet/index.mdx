## Ако вече доставяш софтуер, курсът е за теб.

Предполагаме инженерна преценка: OOP, collections, LINQ, async/await, exceptions, NuGet, тестове, HTTP. Не обясняваме какво е променлива или цикъл — обясняваме кои Python идиоми заместват C# шаблоните, за които посягаш по навик.

**Обещание:** след един концентриран следобед с материала и упражненията можеш да четеш типичен Python код, да стартираш и debug-ваш проект локално, да пишеш малки скриптове и да изпълняваш тестове.

**Не е:** начален курс по програмиране; пълно покритие на Python и CPython internals; курс по Django, FastAPI, pandas или machine learning. Това са следващи стъпки — тук изграждаме езиковия фундамент, който те прескачат.

## Три правила за максимален ефект.

1. **Инсталирай Python локално още в Unit 00.** Упражненията в браузъра са удобство за бърза проверка — не заместват реалния interpreter, debugger и `.venv`.
2. **Решавай „Опитай в браузъра“ и „Изпълни локално“, не само чети.** Най-полезните разлики (референции, truthiness, lazy evaluation) се усещат едва когато изходът те изненада.
3. **Връщай се към капаните.** Всеки модул завършва с кратък списък на C# инстинктите, които да забравиш. Той е по-ценен от самото обяснение — особено след седмица реална работа с Python.
