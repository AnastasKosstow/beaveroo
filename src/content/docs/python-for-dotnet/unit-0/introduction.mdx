## Как работи един урок

Всяка тема в един урок минава през едни и същи стъпки:

1. **C# до Python.** Темата започва с код на C#, който вече познаваш, и същия код на Python до него.
2. **Само разликите.** Обяснението е кратко: какво се пренася направо и къде навикът от C# ще те подведе.
3. **Въпрос за самопроверка.** Един въпрос на тема. Всеки верен отговор вдига процента на урока.

В края на урока те чакат **три малки задачи**. Решаваш ги на своя компютър или в екрана под всяка от тях.

Процентите, които виждаш в менюто и в учебната програма, се пазят само в твоя браузър. Няма акаунти и нищо не се изпраща към сървър.

## Инсталирай Python

1. Отвори [python.org/downloads](https://www.python.org/downloads/) и свали **Python 3.15 или по-нов**.
2. На Windows, на първия екран на инсталатора, отметни **Add python.exe to PATH** и натисни Install Now. Без тази отметка терминалът не намира `python`, както не намира `dotnet`, ако SDK-то не е в PATH.
3. Затвори отворения терминал и отвори нов, за да приеме обновения PATH.

Провери:

```bash
python --version
```

Трябва да видиш `Python 3.15` или по-висока версия. На macOS и Linux командата обикновено е `python3`. На Windows, ако `python` отвори Microsoft Store, ползвай `py --version`. Това е Python launcher-ът: той избира инсталираната версия.

### Отвори папка във VS Code

1. Инсталирай [VS Code](https://code.visualstudio.com/), ако още го нямаш.
2. Отвори Extensions с `Ctrl+Shift+X` (на macOS `Cmd+Shift+X`) и инсталирай разширението [Python](https://marketplace.visualstudio.com/items?itemName=ms-python.python) от Microsoft. То дава подсветка, избор на интерпретатор и бутон за пускане.
3. **File → Open Folder** и избери празна папка, например `python-start`. Няма `.sln` и няма `.csproj`. Папката е целият проект.

Създай в нея файл `hello.py`:

```python title="hello.py"
print("Hello from Python")
```

### Избери интерпретатора

Когато отвориш `.py` файл, VS Code пита кой Python да ползва. Ако не попита, отвори командната палитра с `Ctrl+Shift+P` (на macOS `Cmd+Shift+P`), напиши **Python: Select Interpreter** и избери версията 3.15, която току-що инсталира.

В лентата най-долу трябва да пише нещо като `3.15.x`. Това е изборът на SDK. VS Code не го познава предварително и без него няма с какво да пусне файла.

### Пусни файла

Терминалът на VS Code се отваря в папката, която си отворил, затова намира `hello.py`. Два начина:

- бутонът **Run Python File** горе вдясно в редактора
- команда в терминала (**Terminal → New Terminal**):

```bash
python hello.py
```

На macOS и Linux командата е `python3 hello.py`.

Ако видиш `Hello from Python`, файлът е изпълнен. Няма компилация: интерпретаторът чете файла и го пуска веднага. `print` е `Console.WriteLine`.

За кратък опит без файл напиши само `python`. Отваря се интерактивна конзола, в която всеки ред се изпълнява веднага, както в C# Interactive. Излизаш с `exit()`.

Готов си за [първия урок](/python-for-dotnet/unit-1/types-and-data/).

### Ако не тръгне

- **`python` не се разпознава.** Отвори нов терминал. Ако командата пак липсва, пусни инсталатора отново, избери Modify и отметни Add python.exe to PATH. На Windows `py hello.py` често минава и без това.
- **`python` отваря Microsoft Store.** Потърси **App execution aliases** в Start и изключи **python.exe** и **python3.exe**.
- **VS Code пише, че няма интерпретатор, или пуска стара версия.** Python: Select Interpreter и избери 3.15 или по-нов.
- **Няма бутон Run.** Разширението Python не е инсталирано.
