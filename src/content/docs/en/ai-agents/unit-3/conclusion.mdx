## What you learned

- **RAG** does not change the model, it changes the prompt: you find the text that is needed, add it to the question, and the model answers from it.
- A **retriever** receives a question and returns a few documents. Keyword search finds exact strings, and search by meaning finds synonyms and paraphrases.
- An **embedding** is a vector that describes the meaning of a text. In .NET you get it through `IEmbeddingGenerator`.
- A **vector store** keeps the records with their vectors. `Microsoft.Extensions.VectorData` gives you the same code for memory, SQLite, Qdrant and PostgreSQL.
- **`TextSearchProvider`** does classic RAG in Agent Framework: it searches before every call to the model and adds what it found to the prompt.
- In **Agentic RAG** the search is a tool. The model decides whether, what and how many times to search.
- **Retrieval is more than vector search.** Every tool that brings facts into the prompt is a source of knowledge.

Before you reach for embeddings, ask **where the fact should come from**. If there is little data, put it in the prompt. If it has an exact key, look it up by that key. If you don't know what words you will be asked with, you need a search by meaning. And if there are several sources, let the Agent choose and tell it clearly which one comes first.

## What's next

It is normal if some things are still not completely clear. Go back to the lessons, change the examples and see what happens.

What you built is a working prototype. On the way to a real application you will run into a few topics we did not cover:

- [Data ingestion](https://learn.microsoft.com/dotnet/ai/conceptual/data-ingestion) - reading PDF and Markdown files, cutting them into chunks and writing them to a vector store.
- [Vector store providers](https://learn.microsoft.com/dotnet/ai/vector-stores/overview) - how to move the data from memory to SQLite, Qdrant or PostgreSQL.
- [Evaluation](https://learn.microsoft.com/dotnet/ai/evaluation/libraries) - how to measure with numbers whether the retriever finds the right documents and whether the answers rest on them.
- [Context providers](https://learn.microsoft.com/agent-framework/agents/conversations/context-providers) - memory that the Agent carries across different conversations, built on the same vector stores.
- *Hybrid search* and *reranking* - combining keyword search with search by meaning, and reordering the results with a second model.
