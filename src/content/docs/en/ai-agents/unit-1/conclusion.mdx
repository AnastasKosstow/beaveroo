Congratulations on finishing this first Unit 🥳

You've just **mastered the fundamentals of Agents** and you've created your first AI Agent!

## What you learned

- An **Agent** is a system that uses an LLM to reason, plan and act through tools.
- An **LLM** reads and writes only text, and the **chat template** turns the list of messages into a single prompt.
- A **Tool** is a C# method with a description the model sees in the prompt.
- An Agent works in a **Thought → Action → Observation** cycle.
- You wrote that cycle by hand, and then got it ready-made from `Microsoft.Extensions.AI`.

**It's normal if some things are still not completely clear.** Agents are a complex topic and it commonly takes a while for everything to fall into place.

**Take time to really grasp the material** before continuing. A solid foundation matters before we get to the fun part.
