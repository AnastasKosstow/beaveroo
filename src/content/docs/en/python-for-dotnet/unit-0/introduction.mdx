## How a lesson works

Every topic in a lesson goes through the same steps:

1. **C# next to Python.** The topic starts with C# code you already write, and the same code in Python beside it.
2. **Only the differences.** The explanation is short: what carries over directly, and where the habit from C# will mislead you.
3. **A self-check question.** One question per topic. Every correct answer raises the lesson's percentage.

At the end of the lesson **three small tasks** are waiting. You solve them on your own computer, or in the panel under each one.

The percentages you see in the menu and in the learning path are kept in your browser only. There are no accounts, and nothing is sent to a server.

## Install Python and run a file

Python lives on your machine, the same way the .NET SDK does. There is no account, and the course does not run code for you. There is no project and no `Main`: one file is a whole program.

### Install Python

1. Open [python.org/downloads](https://www.python.org/downloads/) and download **Python 3.15 or newer**.
2. On Windows, on the first screen of the installer, check **Add python.exe to PATH** and click Install Now. Without that checkbox the terminal cannot find `python`, just as it cannot find `dotnet` when the SDK is not on PATH.
3. Close any open terminal and open a new one, so it picks up the updated PATH.

Check:

```bash
python --version
```

You should see `Python 3.15` or a higher version. On macOS and Linux the command is usually `python3`. On Windows, if `python` opens the Microsoft Store, use `py --version`. That is the Python launcher: it picks the installed version.

### Open a folder in VS Code

1. Install [VS Code](https://code.visualstudio.com/) if you do not have it yet.
2. Open Extensions with `Ctrl+Shift+X` (on macOS, `Cmd+Shift+X`) and install the [Python](https://marketplace.visualstudio.com/items?itemName=ms-python.python) extension from Microsoft. It gives you highlighting, interpreter selection and a run button.
3. **File → Open Folder** and choose an empty folder, for example `python-start`. There is no `.sln` and no `.csproj`. The folder is the whole project.

Create a file `hello.py` in it:

```python title="hello.py"
print("Hello from Python")
```

### Select the interpreter

When you open a `.py` file, VS Code asks which Python to use. If it does not ask, open the command palette with `Ctrl+Shift+P` (on macOS, `Cmd+Shift+P`), type **Python: Select Interpreter** and choose the 3.15 version you just installed.

The bar at the bottom should show something like `3.15.x`. That is the SDK choice. VS Code does not know it in advance, and without it there is nothing to run the file with.

### Run the file

The VS Code terminal opens in the folder you opened, so it finds `hello.py`. Two ways:

- the **Run Python File** button at the top right of the editor
- a command in the terminal (**Terminal → New Terminal**):

```bash
python hello.py
```

On macOS and Linux the command is `python3 hello.py`.

If you see `Hello from Python`, the file ran. There is no compilation: the interpreter reads the file and runs it immediately. `print` is `Console.WriteLine`.

For a quick try without a file, type just `python`. An interactive console opens, and every line runs immediately, the same way it does in C# Interactive. You leave it with `exit()`.

You are ready for the [first lesson](/en/python-for-dotnet/unit-1/types-and-data/).

### If it does not start

- **`python` is not recognized.** Open a new terminal. If the command is still missing, run the installer again, choose Modify and check Add python.exe to PATH. On Windows, `py hello.py` often works even without that.
- **`python` opens the Microsoft Store.** Search for **App execution aliases** in Start and turn off **python.exe** and **python3.exe**.
- **VS Code says there is no interpreter, or it runs an old version.** Python: Select Interpreter, and choose 3.15 or newer.
- **There is no Run button.** The Python extension is not installed.
