## What is Microsoft.Extensions.AI?

In the original course this Agent is built with `smolagents` — a lightweight Python library by Hugging Face. In the .NET world its role is played by [`Microsoft.Extensions.AI`](https://learn.microsoft.com/dotnet/ai/microsoft-extensions-ai), a library that **provides a framework for developing your agents with ease**.

This lightweight library is designed for simplicity, but it abstracts away much of the complexity of building an Agent, allowing you to focus on designing your agent's behavior. Its main building blocks are:

- `IChatClient` — a single interface to any LLM provider (OpenAI, Azure, Ollama, Hugging Face Inference Providers, etc.);
- `AIFunctionFactory` — turns a plain C# method into a Tool with a name, description and JSON Schema (we saw it in the [Tools](/en/unit-1/tools/) section);
- `UseFunctionInvocation()` — middleware that automatically runs the **Thought → Action → Observation** cycle: when the model requests a tool, the library invokes it, returns the result as an Observation and feeds everything back to the model until it produces a final answer.

We're going to get deeper into these libraries in the next Unit. Meanwhile, you can also check the <a href="https://learn.microsoft.com/dotnet/ai/quickstarts/use-function-calling" target="_blank">function calling quickstart for .NET</a> or the <a href="https://github.com/dotnet/extensions/tree/main/src/Libraries/Microsoft.Extensions.AI" target="_blank">repo in GitHub</a>, and for the original approach the <a href="https://huggingface.co/blog/smolagents" target="_blank">smolagents blog post</a>.

In short, `smolagents` is a library that focuses on **codeAgent**, a kind of agent that performs **"Actions"** through code blocks, and then **"Observes"** results by executing the code. Our .NET Agent will be a **Function-calling Agent** (see the [Actions](/en/unit-1/actions/) section): the model generates a structured tool call and `Microsoft.Extensions.AI` executes it for us.

## Let's build our Agent!

The original course starts from a ready-made Hugging Face Space ([First_agent_template](https://huggingface.co/spaces/agents-course/First_agent_template) — thanks to <a href="https://huggingface.co/m-ric" target="_blank">Aymeric</a> for this template! 🙌). ```bash
dotnet new console -n FirstAgent
cd FirstAgent
dotnet add package Microsoft.Extensions.AI

Next, you'll need to add your Hugging Face API token so your agent can access the model API. In a Space this is done via *Settings → Variables and Secrets → New Secret* named `HF_TOKEN`; locally we use an environment variable with the same name:

1. First, get your Hugging Face token from [https://hf.co/settings/tokens](https://hf.co/settings/tokens) with permission for inference, if you don't already have one
2. Set it as an environment variable in the terminal you will run the app from:

```powershell

$env:HF_TOKEN = "hf_..."
```

```bash
# bash / zsh
export HF_TOKEN="hf_..."
```

3. Never hardcode the token and never commit it to Git.

### The Tools

Now let's get into the tools! If you want a refresher about tools, don't hesitate to go back to the [Tools](/en/unit-1/tools/) section of the course.

```csharp
/// <summary>The tools available to Alfred.</summary>
public static class AlfredTools
{
    // Below is an example of a tool that does nothing. Amaze us with your creativity!
    [Description("A tool that does nothing yet")]
    public static string MyCustomTool(
        [Description("the first argument")] string arg1,
        [Description("the second argument")] int arg2)
    {
        return "What magic will you build ?";
    }

    [Description("A tool that fetches the current local time in a specified timezone.")]
    public static string GetCurrentTimeInTimezone(
        [Description("A string representing a valid timezone (e.g., 'America/New_York').")] string timezone)
    {
        try
        {
            // Find the time zone (IANA names such as 'Europe/Sofia' are supported)
            TimeZoneInfo tz = TimeZoneInfo.FindSystemTimeZoneById(timezone);
            // Get current time in that timezone
            DateTime localTime = TimeZoneInfo.ConvertTime(DateTime.UtcNow, tz);
            return $"The current local time in {timezone} is: {localTime:yyyy-MM-dd HH:mm:ss}";
        }
        catch (Exception e)
        {
            return $"Error fetching time for timezone '{timezone}': {e.Message}";
        }
    }
}
```

The Tools are what we are encouraging you to build in this section! We give you two examples:

1. A **non-working dummy Tool** that you can modify to make something useful.
2. An **actually working Tool** that gets the current time somewhere in the world. The Python original uses the `pytz` library; in .NET the built-in `TimeZoneInfo` understands IANA time zone names.

To define your tool it is important to:

1. Provide input and output types for your method, like in `GetCurrentTimeInTimezone(string timezone)` → `string` (mandatory in C# — the compiler has your back).
2. **A `[Description]` attribute on the method and on every parameter**. `AIFunctionFactory` is expecting all the arguments to have a **textual description** that it passes to the model (in Python this is the role of the well formatted docstring).

### The Agent

It uses [`openai/gpt-oss-120b`](https://huggingface.co/openai/gpt-oss-120b) as the LLM engine. This is a very capable model with function calling support that we'll access via Inference Providers (an OpenAI-compatible API). The original uses `Qwen/Qwen2.5-Coder-32B-Instruct` — you can change `ModelId` to any chat model that supports tool calling.

```csharp
// --- Token and model -------------------------------------------------------
string hfToken = Environment.GetEnvironmentVariable("HF_TOKEN")
    ?? throw new InvalidOperationException("Set the HF_TOKEN environment variable.");

const string ModelId = "openai/gpt-oss-120b";

// --- The model (Brain) -----------------------------------------------------
// Hugging Face Inference Providers expose an OpenAI-compatible API,
// so we use the OpenAI client with a different Endpoint and wrap it as an IChatClient.
IChatClient model = new OpenAIClient(
        new ApiKeyCredential(hfToken),
        new OpenAIClientOptions { Endpoint = new Uri("https://router.huggingface.co/v1") })
    .GetChatClient(ModelId)
    .AsIChatClient();

// --- Agent: model + automatic Thought → Action → Observation loop ----------
IChatClient agent = new ChatClientBuilder(model)
    .UseFunctionInvocation(configure: options => options.MaximumIterationsPerRequest = 6) // max_steps
    .Build();

var chatOptions = new ChatOptions
{
    Temperature = 0.5f,
    MaxOutputTokens = 2096,
    Tools =
    [
        AIFunctionFactory.Create(AlfredTools.GetCurrentTimeInTimezone),
        // Add your tools here, for example:
        // AIFunctionFactory.Create(AlfredTools.MyCustomTool),
    ],
};
```

This Agent still uses the same Chat Completions API we saw in an earlier section — just wrapped in an `IChatClient`! And `UseFunctionInvocation()` is exactly the loop we wrote by hand in "Dummy Agent Library": stop generating at a tool call, execute the function, append the Observation and call the model again — up to `MaximumIterationsPerRequest` steps.

We will give more in-depth examples when we present the framework in Unit 2. For now, you need to focus on **adding new tools to the list of tools** using the `Tools` property of `ChatOptions`.

For example, you could write a web search tool (the equivalent of the original `DuckDuckGoSearchTool`) with `HttpClient` and a public search API, or an image generation tool through the *text-to-image* task of [Inference Providers](https://huggingface.co/docs/inference-providers/tasks/text-to-image) (the equivalent of the `image_generation_tool` the original loads from the Hub).

**Adding tools will give your agent new capabilities**, try to be creative here!

### The System Prompt

The agent's system prompt is stored in a separate `prompts.yaml` file. This file contains predefined instructions that guide the agent's behavior.

Storing prompts in a YAML file allows for easy customization and reuse across different agents or use cases. In .NET we read it with the `YamlDotNet` library:

```yaml title="prompts.yaml"
system_prompt: |
  You are Alfred, a helpful and polite AI assistant.
  Solve the user's task as best you can. You have access to tools: when a tool can help,
  call it, read its result (the Observation), and only then write your final answer.
  Think step by step before acting. Never invent tool results.
```

```csharp
// --- System prompt from prompts.yaml ---------------------------------------
var deserializer = new DeserializerBuilder().Build();
var promptTemplates = deserializer.Deserialize<Dictionary<string, string>>(File.ReadAllText("prompts.yaml"));

List<ChatMessage> history = [new(ChatRole.System, promptTemplates["system_prompt"])];
```

To copy the file next to the executable, add this to `FirstAgent.csproj`:

```xml title="FirstAgent.csproj"
<ItemGroup>
  <None Update="prompts.yaml" CopyToOutputDirectory="PreserveNewest" />
</ItemGroup>
```

You can check the [original Space's file structure](https://huggingface.co/spaces/agents-course/First_agent_template/tree/main) to see where the `prompts.yaml` file is located there and how it's organized within the project.

### The User Interface

The original uses `GradioUI(agent).launch()` — a web chat interface. In .NET the simplest equivalent is a console chat loop; later you can replace it with a Blazor or ASP.NET Core app.

```csharp
// --- Console chat (instead of GradioUI) ------------------------------------
Console.WriteLine("Alfred is ready. Ask a question (or 'exit'):");

while (true)
{
    Console.Write("\nYou: ");
    string? input = Console.ReadLine();
    if (string.IsNullOrWhiteSpace(input) || input.Equals("exit", StringComparison.OrdinalIgnoreCase))
    {
        break;
    }

    history.Add(new ChatMessage(ChatRole.User, input));

    ChatResponse response = await agent.GetResponseAsync(history, chatOptions);
    history.AddMessages(response);

    // verbosity_level=1: show the invoked tools and their observations
    foreach (ChatMessage message in response.Messages)
    {
        foreach (AIContent content in message.Contents)
        {
            switch (content)
            {
                case FunctionCallContent call:
                    Console.WriteLine($"  Action: {call.Name}({JsonSerializer.Serialize(call.Arguments)})");
                    break;
                case FunctionResultContent result:
                    Console.WriteLine($"  Observation: {result.Result}");
                    break;
            }
        }
    }

    Console.WriteLine($"Alfred: {response.Text}");
}
```

### Publishing to a Hugging Face Space (optional)

Hugging Face Spaces support [Docker Spaces](https://huggingface.co/docs/hub/spaces-sdks-docker), which can run any .NET application. To share your Agent with a Gradio-like interface, turn the console app into a small ASP.NET Core or Blazor app listening on port `7860`, add a `Dockerfile` based on the `mcr.microsoft.com/dotnet/aspnet` image, and create a Space with the "Docker" SDK.
